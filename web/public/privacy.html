Privacy policy

The Library · effective October 9, 2026

Who this covers

The Library is a private, single-user newsletter reader operated by Sandip Dev for personal use. It has no other users and does not offer accounts to anyone.

Google data it accesses

With the owner's permission, The Library uses the Gmail API with read-only access (https://www.googleapis.com/auth/gmail.readonly) to the owner's own Gmail account. It processes only messages that match the owner's newsletter labels and senders. For any other message it reads, it keeps only the sender, subject and date, so the message is not fetched again. It never sends, deletes or changes email.

How the data is used

To show newsletters in the reader, to keep the owner's read state and Relevant/Irrelevant ratings, and to rank issues for the owner. Short summaries and topic tags may be generated with Amazon Bedrock inside the owner's AWS account. The data is not used for advertising and is not used to train models.

Where it is stored and for how long

In the owner's Amazon Web Services account, in the US East (N. Virginia) region. Original messages are deleted after 30 days and cleaned copies after 365 days. Extracted text, ratings and metadata are kept until the owner deletes them.

Sharing

The data is not sold or shared. Only the owner can sign in, with a password and an authenticator code. Amazon Web Services hosts the data as the infrastructure provider.

Google API Services User Data Policy

The Library's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions, which stops all new reads. The owner can delete the stored data at any time.
