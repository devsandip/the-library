# The Library

A private, single-user newsletter reader. It ingests newsletters from Gmail, learns what I care about from Relevant/Irrelevant ratings, and puts the best items on top. Served at `https://sandip.dev/thelibrary`.

Status: Phase 1 rebuild in progress. See the build plan for the current milestone.
